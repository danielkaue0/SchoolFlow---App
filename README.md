## 📋 Sobre o Projeto

O **Controle Escolar** é um aplicativo desktop para Windows desenvolvido para ajudar estudantes a organizar suas tarefas, gerenciar matérias e aumentar a produtividade com o método Pomodoro.

### ✨ Funcionalidades

| Funcionalidade | Descrição |
|----------------|-----------|
| 📋 **Tarefas** | CRUD completo (criar, editar, excluir, concluir) |
| 📁 **Matérias** | Gerenciamento de disciplinas com notas e horas |
| 🍅 **Pomodoro** | Timer com ciclo 25/5 automático |
| ⚙️ **Configurações** | Tema claro/escuro |
| 💾 **Armazenamento** | Local (JSON) |

## 🚀 Download e Instalação

### Baixar o Aplicativo

1. Acesse a página de [Releases](https://github.com/seu-usuario/controle-escolar/releases)
2. Baixe o arquivo `ControleEscolarHQ.exe`
3. Execute o arquivo baixado
4. O aplicativo não precisa de instalação

### Requisitos do Sistema

| Item | Requisito |
|------|-----------|
| SO | Windows 7, 8, 10 ou 11 |
| RAM | 512 MB (mínimo) |
| Armazenamento | 50 MB livres |
| Admin | Não necessário |
