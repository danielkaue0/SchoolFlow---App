SchoolFlow - Controle Escolar

Aplicativo para organização escolar.

Funções:
- gerenciamento de tarefas
- controle de faltas
- calendário de eventos
- grupos de estudo

Como usar:
1. Abra SchoolFlow.exe
2. Adicione suas tarefas e matérias
3. Use o calendário para eventos
